## 4. 藏馆总身价、重复合成与后续扩展规范

### 4.1 藏馆成长与碎片保底合成公式
1. **【藏馆总身价】实时滚动**：每次开出公仔（无论是否重复），其估值直接累加进玩家顶部常驻的**【我的藏馆总身价】**（如 `总身价：1,896.4 万`），并自动晋升头衔（`拾荒新手` → `淘沙达人` → `百万富翁` → `千万大红收藏家`）。
2. **差异化保底合成（防溢出）**：
   - **普通保底合成（消耗 `5 碎片`）**：随机合成 1 款当前**未解锁**的公仔（按未解锁池品质权重抽取）。
   - **高阶定向冲刺（消耗 `25 碎片`）**：必出 1 款当前**未解锁的 `🟣紫 / 🟡金 / 🔴大红`** 公仔！让长期游玩的收集党 100% 有盼头凑齐大红全图鉴。
