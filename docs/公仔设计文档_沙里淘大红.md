## 4. 藏馆总身价、重复合成与后续扩展规范

### 4.1 藏馆成长与碎片保底合成公式
1. **【藏馆总身价】实时滚动**：每次开出公仔（无论是否重复），其估值直接累加进玩家顶部常驻的**【我的藏馆总身价】**（如 `总身价：1,896.4 万`），并自动晋升头衔（`拾荒新手` → `淘沙达人` → `百万富翁` → `千万大红收藏家`）。
2. **差异化保底合成（防溢出）**：
   - **普通保底合成（消耗 `5 碎片`）**：随机合成 1 款当前**未解锁**的公仔（按未解锁池品质权重抽取）。
   - **高阶定向冲刺（消耗 `25 碎片`）**：必出 1 款当前**未解锁的 `🟣紫 / 🟡金 / 🔴大红`** 公仔！让长期游玩的收集党 100% 有盼头凑齐大红全图鉴。

### 4.2 后续公仔无限扩展标准（`FigurineSchema`）
后续更新第 31~60+ 款公仔时，只需在 [`data/figurines.json`](../data/figurines.json) 的 `series` 数组中新增套系对象与公仔条目（碎片值由 `rarities` 表按品质统一给出，合成规则见 `craftRules`），图鉴页支持按套系 Tab 左右滑动切换：

```json
{
  "seriesId": "series_03_fortune",
  "seriesName": "第三弹：暴富招财宝库",
  "unlockReward": { "type": "sand_skin", "id": "skin_gold_glitter", "name": "流金溢彩沙", "title": "招财宗师" },
  "items": [
    {
      "id": "fig_031",
      "name": "铜钱小锦鲤",
      "rarity": "BLUE",
      "valuation": 26000,
      "species": "锦鲤",
      "archetype": "铜钱鳞片",
      "tags": [],
      "quote": "转发这条小锦鲤，下一罐必出大红！"
    }
  ]
}
```

| 字段 | 去重作用 |
| :--- | :--- |
| `id` | 由注册表发号（`fig_XXX` 连续递增），**退役后也不复用** |
| `name` | 与全部现存 + 已退役公仔做名称相似度（字二元组 Jaccard 与最长公共子序列取大）检测，≥0.6 拒绝发号，防止“纯金招财橘猫 / 纯金招财大橘猫”式换皮 |
| `species` + `archetype` | 物种 + 造型母题组合键，**完全相同报错**；同物种不同母题允许但会提示 |
| `tags` | 机制标签，如 `crystal`（被 `box_ice` 加权） |

**新增流程**：`node tools/registry.js allocate figurine "铜钱小锦鲤"` → 写入 JSON → 在 [`data/art/prompts.json`](../data/art/prompts.json) 增加同 ID 的生图提示词（提示词相似度 ≥0.80 报错）→ `node tools/validate-content.js --fast` → `node tools/registry.js bootstrap`。详见 [内容去重与校验规范](内容去重与校验规范.md)。
